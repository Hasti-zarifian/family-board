
# Family Board

Family Board is a responsive, Persian-language board game store website developed as the final project for the Karyar Web Design course.

## Project Pages

- **Home Page (Page1):** Displays six board games with product cards and a filter sidebar.
- **Product Details (Page2):** Shows information, images, and pricing for the Ark Nova board game.
- **Registration Page (Page3):** Includes a user registration form with HTML validation.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- Responsive Design
- CSS Media Queries
- Vazirmatn Font

## Features

- Right-to-left (RTL) Persian layout
- Responsive design for desktop and mobile
- Light and dark color schemes
- Navigation between pages
- Custom-styled form controls
- HTML form validation

## Project Structure

- `Page1/index.html` - Home page
- `Page2/index.html` - Product details page
- `Page3/index.html` - Registration page
- `style.css` - Shared stylesheet
- `fonts/` - Local Vazirmatn font
- `Page1/Images/` - Product images

## How to Run

Download or clone the repository and open `Page1/index.html` in a web browser.

## Note

This is a static educational project built with HTML and CSS only. The registration form does not create real user accounts.
